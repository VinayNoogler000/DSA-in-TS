# DSA (Data Strutures and Algorithms) in TypeScript (or JS)

## Overview
This repository consists of source-code of DSA in TS (which can be obviously converted to JS easily, by just removing the types) which I've created to practice DSA in TS, 'cause I'm going to use it the most as a developer (especially a MERN-Stack dev) for a long-time. And, FYI, I've already completed learning all the important Data Structures (from arrays to graphs to segment tress) and Algos (from sorting/searching to dynamic programming), but in Java, that was two years ago (in 2024). So, because my interest and goals are "development-focused" especially Web Dev, that's why my I'm going to practice/revise DSA in TS to become very strong enough in it, and also being able to use the concepts in real-world apps (instead of learning and forgetting about them —happened after learning DSA in Java), especially when it's just 1 week of learning TS fundamentals from [Chai-aur-TS YT Playlist](https://youtube.com/playlist?list=PLu71SKxNbfoBkkr8lblqtsJvxrw3j1tWC&si=6zp0a4XwG1gKMZGN).

## Intention behind Creation
My intention behind creating this repo is to store the DSA source-code in such a place which is publicly accessible from anywhere, so that I can refer to it easily and any other person can also do the same thing.


## Use Cases of this Repo
1. You can understand the DSA concepts by just reading the implementation in TS from anywhere and anytime.
2. You can copy-paste the implementation to your applications to build a specific functionality.
3. You can teach the DSA concepts easily to anyone without wasting time of searching the source-code.


## Folder Structure
All the source code is inside `src` folder
- `patterns.ts` - consists of source-code to print different patterns (from easy to hard level) for building programmatic & logical thinking
- `input.ts` - shows different possible ways or approaches to take input from the user via terminal


## Run it locally
To install dependencies:

```bash
bun install
```

To run:

```bash
bun run src/[file-name]
```

This project was created using `bun init` in bun v1.3.11. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
